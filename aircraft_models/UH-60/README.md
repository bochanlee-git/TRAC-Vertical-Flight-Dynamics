# UH-60 Aircraft Model

The UH-60 helicopter serves as the baseline conventional rotorcraft configuration used in the development and validation of the Texas A&M University Rotorcraft Analysis Code (TRAC).

The configuration documented here summarizes the aircraft-specific information reported in Lee (2021). It is intended to describe how the UH-60 is represented within the TRAC framework rather than to provide a complete engineering database or a complete public implementation of the aircraft model.

---

## 1. Role of the UH-60 in TRAC

The UH-60 was selected as the baseline rotorcraft for TRAC because extensive flight-test data were available for model comparison and validation.

Within TRAC, the aircraft is represented as an assembly of independently modeled components:

- fuselage
- main rotor
- tail rotor
- horizontal tail (stabilator)
- vertical tail (fin)

The loads generated by these components are transformed into the aircraft body-fixed coordinate system and combined to form the complete nonlinear aircraft model.

The UH-60 configuration was used to demonstrate:

- component-based rotorcraft modeling
- nonlinear flight-dynamics analysis
- trim computation
- linear model extraction
- comparison with flight-test data
- flight-control system development
- autonomous-flight simulation

The UH-60 implementation therefore serves as the primary reference configuration for demonstrating the conventional-helicopter modeling capability of TRAC.

---

## 2. Aircraft Model Architecture

The UH-60 model follows the modular architecture of TRAC.

| Component | Representation |
| --- | --- |
| Fuselage | Rigid-body dynamics with aerodynamic loads based on empirical and aerodynamic data |
| Main rotor | Individual blade modeling with aerodynamic and inertial loads, flapping and lead-lag motion, and dynamic inflow |
| Tail rotor | Simplified rotor thrust and torque representation with dynamic inflow |
| Horizontal tail | Stabilator aerodynamic loads based on local flow conditions and aerodynamic coefficient data |
| Vertical tail | Fin aerodynamic loads based on local flow conditions and aerodynamic coefficient data |
| Aircraft dynamics | Nonlinear six-degree-of-freedom rigid-body equations coupled with rotor and inflow dynamics |

The modular formulation allows individual component models to be modified or replaced without restructuring the entire aircraft model.

Detailed governing equations are documented in [Mathematical Model](../../docs/mathematical-model.md).

## 4. Aerodynamic Representation

The UH-60 implementation combines rotor aerodynamic modeling with empirical or tabulated aerodynamic information for the non-rotating aircraft components.

### Main Rotor

The main rotor formulation includes:

- blade-element aerodynamic loading
- blade flapping motion
- blade lead-lag motion
- rotor inflow dynamics
- rotor force and moment calculation
- rotor power calculation

The baseline model uses the Pitt-Peters linear dynamic inflow formulation rather than a free-wake or CFD-based wake model.

### Fuselage

Fuselage aerodynamic loads are represented using experimental or empirical aerodynamic information.

The aerodynamic forces and moments are evaluated using local flow conditions and transformed to the aircraft body-fixed coordinate system.

### Empennage

The horizontal and vertical tail surfaces are modeled using local flow conditions and aerodynamic coefficient lookup information.

The horizontal stabilator incidence is scheduled as a function of flight condition in the documented UH-60 model.

## 5. Control and Trim Variables

The conventional UH-60 configuration uses four primary control inputs:

- main-rotor collective
- longitudinal cyclic
- lateral cyclic
- tail-rotor control

TRAC determines the aircraft controls and internal model variables required to satisfy specified steady-flight conditions.

Trim unknowns include:

- control angles
- fuselage attitude variables
- rotor flapping coefficients
- rotor lead-lag coefficients
- main-rotor inflow coefficients
- tail-rotor inflow

The detailed trim formulation is documented in [Trim Analysis](../../docs/trim-analysis.md).

## 6. Analyzed Flight Conditions

The UH-60 model was evaluated over several steady-flight conditions.

### Hover and Forward Flight

Forward-flight calculations were performed from hover through high-speed flight.

Reported outputs include:

- main-rotor power
- fuselage attitude
- rotor flapping and lead-lag motion
- rotor inflow
- collective control
- longitudinal cyclic control
- lateral cyclic control
- pedal control

### Climbing and Descending Flight

Climb and descent cases were evaluated by varying flight-path angle while maintaining a specified forward-flight condition.

The dissertation reports calculations over a flight-path-angle range from approximately:

$$
-20^\circ \leq \gamma \leq 25^\circ
$$

at a stated speed of 60 knots for the reported comparison case.

### Steady Turning Flight

Steady-turn conditions were evaluated using nonzero turn rates.

The reported turn-rate sweep extends approximately from:

$$
-25^\circ/\mathrm{s}
\leq
\dot{\psi}
\leq
25^\circ/\mathrm{s}
$$

These cases demonstrate the ability of the model to compute trimmed operating conditions beyond straight-and-level forward flight.

## 7. Validation

The UH-60 configuration provides the primary flight-test validation case for the TRAC framework.

Model predictions were compared with available U.S. Army UH-60 flight-test data.

### 7.1 Main-Rotor Power

Two forward-flight power comparison conditions are reported:

| Gross weight | Density altitude | Speed range |
| --- | --- | --- |
| 16,360 lb | 3,670 ft | Hover to 160 knots |
| 16,000 lb | 5,250 ft | Hover to 160 knots |

The reported comparisons show better agreement at moderate and higher forward speeds.

At low forward speeds, particularly below approximately 30 knots, the baseline model underpredicts main-rotor power.

The dissertation attributes this discrepancy primarily to the simplified linear inflow representation and rotor-wake interference effects that become more important at low advance ratio.

---

### 7.2 Aircraft Attitude

Predicted UH-60 fuselage pitch and roll angles were compared with flight-test measurements.

The reported pitch-angle predictions correlate well with the available measurements over the investigated forward-speed range.

The predicted roll angle follows the overall measured trend, although some underprediction is reported at higher forward speeds.

---

### 7.3 Control Inputs

The following control quantities were compared with available flight-test data:

- collective stick
- longitudinal cyclic
- lateral cyclic
- pedal

The dissertation reports close agreement between predicted and measured control trends for the investigated steady-flight conditions.

Additional control comparisons were performed for climbing, descending, and steady-turning flight.

---

## 8. Model Limitations

The UH-60 results should be interpreted within the scope of the documented model and available validation data.

Important limitations include:

- low-speed main-rotor power is underpredicted in the reported baseline model
- the Pitt-Peters inflow formulation does not explicitly resolve the complete rotor wake
- available climb/descent and turning flight-test data are limited
- predicted internal rotor quantities are not necessarily independently validated measurements
- steady-flight validation does not establish transient-response accuracy
- validation of the UH-60 configuration does not imply equivalent accuracy for other aircraft modeled using TRAC

The model therefore represents a balance between computational efficiency and physical modeling detail suitable for flight-dynamics and control-oriented research.

Detailed validation evidence and limitations are documented in [Validation](../../docs/validation.md).

## 9. Linearization and Flight-Control Application

Trimmed UH-60 operating points can be used as reference conditions for linear model extraction.

The nonlinear TRAC equations are linearized around selected trim conditions to obtain state-space models suitable for:

- stability analysis
- dynamic-mode analysis
- flight-control design
- aircraft response analysis

The dissertation demonstrates the use of extracted UH-60 models with Linear Quadratic Regulator (LQR) control for autonomous ship-approach and landing simulations.

Different trim-based models are used to represent different portions of the flight trajectory.

These simulations demonstrate the control-oriented application of the UH-60 TRAC model but should not be interpreted as flight-test validation of the complete autonomous UH-60 system.

---

## 10. Relationship to the TRAC Framework

The UH-60 model is one implementation of the broader TRAC architecture.

TRAC is not designed as a UH-60-specific simulation program.

Instead, the UH-60 configuration provides a conventional-helicopter baseline from which the framework's modeling, trim, linearization, validation, and flight-control capabilities can be demonstrated.

The modular aircraft representation also allows the framework to be adapted to configurations with substantially different rotor and propulsion architectures.

Application to the Harmony Aria coaxial rotorcraft provides one example of this extensibility.
